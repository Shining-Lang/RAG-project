# LSN 销售流程作战手册

## 适用范围

本文档用于销售 Agent 在解释销售数据、生成跟进建议、复盘异常订单、辅助主管做销售辅导时引用。它不是单纯的话术文档，而是把销售流程、管道推进、发现式沟通和数据复盘统一成一个可执行框架。

## 一、销售流程总览

LSN 推荐将销售过程拆成 7 个阶段：目标客户识别、线索触达、资格判断、需求发现、方案匹配、商务推进、成交与复购。销售 Agent 在回答问题时，应优先判断用户询问落在哪个阶段，再给出具体建议。

目标客户识别阶段关注行业、公司规模、预算能力、业务痛点、采购周期和现有替代方案。此阶段不要过早报价，应先判断客户是否符合 ICP。

线索触达阶段关注触达渠道和第一句话价值。销售员应避免只发送产品介绍，而要用一个与客户业务相关的触发点开启沟通，例如“近期贵司渠道订单增长较快，是否正在评估自动化销售分析工具？”

资格判断阶段确认四类信号：客户是否存在明确问题、是否有决策人或影响人参与、是否有预算或资源投入、是否有可量化的时间窗口。若缺少两项以上，应降低优先级或进入培育池。

需求发现阶段需要追问客户当前流程、失败成本、成功标准、内部决策链路、历史尝试方案。发现式沟通的关键不是问完清单，而是让客户承认问题的业务影响。

方案匹配阶段要把产品能力映射到客户业务问题。演示时不要只展示功能按钮，应围绕客户最关心的指标组织，例如订单转化率、销售预测准确率、退单率、客户响应时长。

商务推进阶段应记录价格、交付范围、付款方式、采购节点、法务风险、竞品信息。大额折扣必须换取更强承诺，例如更快签约、更大采购量、更长合同周期或客户案例授权。

成交与复购阶段要交接客户成功团队，并在 30 天内确认首次价值达成情况。若客户未达到首个价值目标，销售 Agent 应提醒销售员跟进培训、配置、使用率和关键用户反馈。

## 二、资格判断标准

高优先级机会通常同时具备以下信号：

1. 客户痛点清晰，且与收入、成本、效率或风险直接相关。
2. 客户能描述“不解决”的业务代价。
3. 已识别决策人、使用人、采购人和技术评估人。
4. 存在明确预算、项目资源或采购窗口。
5. 客户愿意承诺下一步动作，例如试点、演示、方案评审或报价确认。

中优先级机会通常只有痛点，但缺少决策路径或时间窗口。此类机会需要推动关键人会面，或者用行业案例建立紧迫感。

低优先级机会通常只有兴趣，没有业务影响，也没有下一步承诺。此类机会应进入培育池，不应占用大量销售资源。

## 三、发现式沟通问题库

销售员可以使用以下问题挖掘客户真实需求：

- 当前销售管理中最耗时的环节是什么？
- 哪个指标最影响本季度目标达成？
- 如果这个问题继续存在，会影响多少收入、成本或客户满意度？
- 目前是否已经尝试过表格、BI、CRM 或其他工具？
- 谁会参与评估，谁拥有最终审批权？
- 如果方案有效，客户希望多久看到结果？
- 采购流程中最可能卡住的点是什么？
- 与竞品相比，客户最关注价格、部署、集成、安全还是服务？

## 四、数据驱动复盘原则

当销售额下降时，先拆成订单数下降、客单价下降、产品结构变化、区域结构变化、退单率升高，再判断销售动作问题。不要直接归因于销售员能力。

当大区异常下滑时，优先比较近 14 天与过去 4 周均值，再要求大区负责人补充渠道活动、库存和市场事件。若近期订单数下降但客单价上升，说明不是简单需求萎缩，可能是小客户断层或线索结构变化。

当产品连续零销售时，优先检查库存、价格、曝光、渠道覆盖和竞品替代，再判断销售动作问题。若库存正常但曝光下降，应联系运营；若曝光正常但转化下降，应复盘页面、价格和竞品。

当销售员退单率偏高时，应抽查成交承诺、客户画像匹配度、售后原因、合同条款和交付能力。若退单集中在某类客户，应调整客户筛选标准；若退单集中在某类产品，应反馈产品或履约团队。

## 五、Agent 回答规范

销售 Agent 回答时应采用“结论 - 证据 - 建议”结构。

结论部分直接回答用户问题，例如“本季度 Top 3 销售员为张伟、林敏、周丽”。

证据部分必须给出时间范围、统计口径和关键数字，例如“统计范围为 2026-07-01 至 2026-08-08，仅统计 COMPLETED 订单”。

建议部分必须可执行，不要只说“加强跟进”。应具体到动作，例如“核查 SKU-8821 库存和渠道曝光”“抽查王芳近 4 单退单原因”“安排华北区渠道活动复盘会”。

当数据不足时，应明确说明缺口，例如“当前没有线索阶段数据，因此无法计算阶段转化率，只能基于订单结果做复盘”。

# LSN 产品定价与竞品应对 Battlecard

## 使用场景

本文档用于销售 Agent 回答价格异议、产品滞销、SKU 连续零销售、竞品比较、折扣审批建议等问题。它适用于销售员、销售主管、渠道经理和销售运营团队。

## 一、价格异议处理原则

遇到价格异议时，不要第一时间降价。先确认客户是否认可价值，再判断价格异议是真实预算限制，还是客户用于谈判的常规动作。

建议销售员先问三个问题：

1. 如果价格不是问题，当前方案是否满足核心需求？
2. 客户希望通过采购解决哪个业务指标？
3. 客户正在比较的替代方案是什么，比较维度是价格、功能、服务还是交付周期？

如果客户没有认可价值，折扣不会提高赢率，只会压缩利润。应回到需求发现和价值证明。

如果客户认可价值但预算有限，可以提供低门槛试点、分阶段采购、缩小首期范围或延长合同周期，而不是直接打折。

## 二、折扣审批红线

折扣必须换取客户承诺。常见可交换条件包括更快签约、更大采购量、更长合同周期、预付款、客户案例授权、联合发布或明确续费条款。

以下情况不建议给大额折扣：

- 客户没有明确决策人。
- 客户没有明确采购时间。
- 客户只要求最低价，但没有说明业务目标。
- 销售员没有记录竞品名称和比较维度。
- 当前订单已经接近成本线。

以下情况可以考虑战术性折扣：

- 客户是标杆行业客户，有案例价值。
- 客户愿意签多年合同或更大采购量。
- 客户正在与明确竞品做最终比较。
- 折扣能换取更快付款或更低交付风险。

## 三、产品滞销诊断

当某个 SKU 连续零销售时，应按以下顺序排查：

1. 库存：是否缺货、是否部分渠道缺货、是否补货周期过长。
2. 价格：是否高于主要竞品，是否缺少促销或套餐。
3. 曝光：搜索排名、页面访问、渠道推荐位是否下降。
4. 转化：页面描述、图片、评价、试用门槛、支付方式是否影响成交。
5. 渠道：是否只有单一区域或渠道在推广，是否渠道激励不足。
6. 客户匹配：产品是否推给错误客户群，例如高端产品被推给价格敏感型客户。
7. 销售动作：销售员是否缺少案例、话术、技术支持或试用环境。

## 四、竞品应对话术

不要攻击竞品。应围绕客户最关心的业务指标做差异化说明。

如果竞品更便宜：强调总拥有成本，包括部署成本、维护成本、培训成本、二次开发成本、集成成本和售后响应成本。

如果竞品功能更多：确认客户真正需要哪些功能，不要陷入功能清单比较。把讨论拉回客户的成功标准。

如果竞品已有客户关系：争取小范围试点或关键场景验证，用事实替代口头承诺。

如果客户要求“同价匹配”：先确认客户是否认可 LSN 方案的独特价值，再决定是否进入商务审批。

## 五、Agent 建议模板

当用户问“某产品为什么卖不动”时，Agent 应输出：

- 当前现象：连续零销售天数、最后成交日期、相关大区或销售员。
- 初步判断：优先检查库存、价格、曝光、渠道覆盖和竞品替代。
- 下一步动作：列出 3 到 5 个明确检查项。
- 需要补充的数据：库存、曝光、点击、加购、竞品价格、渠道活动。

当用户问“是否应该打折”时，Agent 应输出：

- 当前折扣是否必要。
- 客户是否已经认可价值。
- 折扣应换取什么承诺。
- 如果不能打折，可替代方案是什么。
